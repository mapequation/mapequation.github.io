[netgamut](https://mapequation.org/netgamut/) is now on PyPI. Install it with
`pip install netgamut`. It finds, downloads, and caches network datasets from
seven sources: SNAP, Netzschleuder, KONECT, OGB, PyTorch Geometric, AHORN, and
curated path data. The catalog ships with the package, so you can search by
domain, size, or statistics before you download anything. One domain vocabulary
covers all sources, so you can compare methods across kinds of systems. Each
dataset is downloaded once per machine and shared by all your projects. Browse
every dataset in the
[catalog explorer](https://mapequation.org/netgamut/explorer.html)
([GitHub](https://github.com/mapequation/netgamut)).
