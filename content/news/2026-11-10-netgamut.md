[netgamut](https://mapequation.org/netgamut/) is a Python package that finds,
downloads, and caches network datasets from multiple sources, including SNAP,
Netzschleuder, and KONECT. As the name suggests, it aims to cover the full
gamut of networks and serve as a proving ground for community detection
methods such as [Infomap](https://mapequation.org/infomap/). The catalog ships
with the package, so you can search by domain, size, or statistics before you
download anything, or browse it in the interactive
[catalog explorer](https://mapequation.org/netgamut/explorer.html). Install it
with `pip install netgamut`
([GitHub](https://github.com/mapequation/netgamut)).
