This release makes Infomap's results more correct. Hierarchical solutions get
about 0.2–0.5% shorter codelengths, because modules that do not pay for their
codebook are now removed. If you rerun an analysis made with an earlier version,
expect the partition to change even with the same seed. If you used
`--entropy-corrected`, `--regularized` or `--meta-data`, rerun: fixes to these
options change the codelength and the modules found. The entropy correction,
for example, was counted in nats instead of bits. To tell an intended change
from a regression, check the new list of
[result changes](https://mapequation.org/infomap-python-docs/result-changes.html)
by release and flag. Output files now record the seed and a fingerprint of the
input, so a result can be traced to the run that made it
([changelog](https://github.com/mapequation/infomap/blob/master/CHANGELOG.md)).
