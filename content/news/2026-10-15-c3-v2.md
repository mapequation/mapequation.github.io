[C3](https://mapequation.org/c3/) generates distinct, deterministic categorical
colors for maps and charts. Version 2 places hues on the OKLCH hue circle or
along any d3 color scheme, and adds tones, seed colors, and nested colors for
hierarchies, with each child varying within its parent's range. It now comes in
TypeScript (`npm install @mapequation/c3`) and Python (`pip install c3-colors`)
with the same functions and the same colors, and has an interactive explorer
([changelog](https://github.com/mapequation/c3/releases)).
